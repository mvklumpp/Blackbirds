# Blackbirds

This repository contains code associated with the following manuscript: Stable immune function during moult regardless of age-specific moulting strategy in a European passerine (Klumpp & Hegemann, resubmitted, November 2025)

## Code

Moult_Analyses&Figures.R – Code to replicate the statistical analyses and figures (updated in November 2025)

## Data

The data of this study is publicly available in the Dryad Digital Repository: https://doi.org/10.5061/dryad.612jm64kb
