# Blackbirds

This repository contains code associated with the following manuscript: Klumpp, M. V. & Hegemann, A. 2025. Stable immune function during moult regardless of age-specific moulting strategy in a European passerine. – J. Avian Biol. 2025: e03531.

## Code

Moult_Analyses&Figures.R – Code to replicate the statistical analyses and figures.
DOI: https://doi.org/10.5281/zenodo.18186749

## Data

The data of this study is publicly available in the Dryad Digital Repository: DOI: https://doi.org/10.5061/dryad.612jm64kb
